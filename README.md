# Ali Raza Shafqat — Portfolio

Editable static portfolio built from the supplied CV. Open `index.html` locally or deploy the folder to any static host.

## Update content

- Profile details: `content/profile.json`
- Publication records: `content/publications.json` and the display list in `script.js`
- Verification notes: `content/source-register.json` and `content/requires-review.json`
- Replace the CV at `assets/250226 Ali Raza Shafqat CV.docx` when a newer approved version is available.

## Deployment

Upload the project folder to Netlify Drop, Cloudflare Pages, GitHub Pages, or any static hosting service. No environment variables are required. The contact links use email and phone; connect a form provider later if a server-backed form is needed.
