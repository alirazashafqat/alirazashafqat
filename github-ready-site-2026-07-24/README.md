# Ali Raza Shafqat — Portfolio

Premium multi-page portfolio positioning Ali Raza Shafqat as a circular materials consultant, researcher, educator, and startup entrepreneur.

## Pages

- Home: `index.html`
- Profile: `about.html`
- Research: `research.html`
- Consulting: `consulting.html`
- Publications: `publications.html`
- Experience: `experience.html`
- ReComp Solutions and innovation: `innovation.html`
- Awards, funding, and professional service: `recognition.html`
- Gallery: `gallery.html`
- Contact: `contact.html`

## Updating the site

Major profile facts come from the supplied CV. Update the relevant HTML page when a position, publication, project, award, or contact detail changes. Optimized images are stored in `assets/photos/`.

The generated circular-composite image is used as a clearly identified conceptual visualization, not as documentary evidence of a research sample.

## Publishing

Copy the complete project contents to the root of the `alirazashafqat/alirazashafqat` GitHub repository and enable GitHub Pages from the `main` branch root.
